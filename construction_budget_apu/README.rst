Construction budgets with unit price analysis (APU), chapters, line
items, versioning, version comparison, and synchronization to OCA
accounting budgets (``account_budget_oca``) for planned vs actual
tracking.

.. contents::
   :local:

Usage
=====

#. Configure a default budgetary position on the construction budget. #.
Create chapters and line items; open APU to detail unit costs. #.
Submit, approve, and freeze a version to sync totals to a crossovered
budget.
